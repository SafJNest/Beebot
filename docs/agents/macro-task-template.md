# Macro-task template

## Objective

Describe the concrete outcome of this task.

## Dependencies

List accepted ADRs, previous macro-tasks and external prerequisites.

## Scope

List the behavior and ownership this agent may change.

## Out of scope

List related behavior that must remain untouched.

## Candidate files

List current files and expected canonical destinations. Treat this list as a boundary, not as permission to refactor unrelated code.

## Invariants

List names, owners, API behavior, persistence and cache rules that must remain true.

## Implementation plan

Use ordered steps. Each step must have one observable result.

## Acceptance criteria

List conditions that the main agent can verify without interpreting intent.

## Verification

Record commands, tests, static checks and any unavailable tooling.

## Handoff to main agent

Report:

- summary of changes;
- changed files;
- decisions or deviations;
- verification results;
- risks and follow-ups;
- confirmation that the gate passes or the reason it does not.
